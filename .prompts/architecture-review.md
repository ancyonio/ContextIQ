# Task: Architecture Review

## Goal
Evaluate a proposed design for scalability, security, and maintainability.

## Output
1. Design Review
2. Identified Risks
3. Recommended Improvements
4. Alignment with Existing patterns

## Instructions
Use ContextIQ tools to understand the current system architecture before proposing changes.
- `search_semantic` to find similar existing designs.
- `get_module_summary` for high-level module overview.
- `file_skeleton` to see the structure of candidate modules.
